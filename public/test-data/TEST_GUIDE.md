# 测试数据指南

本文档说明如何获取测试数据来验证新增的三个功能：

## 1. 视频抽帧工具 (Video Frame Extractor)

### 获取测试视频

#### 方式一：使用浏览器录制测试视频
1. 打开浏览器开发者工具 (F12)
2. 或使用任何屏幕录制工具录制 10-30 秒的视频
3. 保存为 MP4、WebM 或 MOV 格式

#### 方式二：使用在线测试视频
可以使用以下在线资源获取测试视频：
- https://test-videos.co.uk/ (提供各种格式的测试视频)
- 或从视频网站下载短视频片段

#### 方式三：使用 FFmpeg 生成测试视频
如果已安装 FFmpeg，可以运行以下命令生成测试视频：
```bash
# 生成一个 10 秒的测试视频
ffmpeg -f lavfi -i testsrc=duration=10:size=640x480:rate=30 -c:v libx264 test_video.mp4

# 生成带颜色渐变的测试视频
ffmpeg -f lavfi -i "color=c=blue:duration=10:size=640x480,format=yuv420p" -c:v libx264 blue_video.mp4
```

### 测试步骤
1. 上传视频文件
2. 选择提取模式：
   - **单帧模式**：输入具体时间（秒）提取一帧
   - **按间隔模式**：设置间隔秒数和最大帧数
   - **关键帧模式**：提取所有关键帧（I帧）
3. 设置时间范围（可选）
4. 选择输出格式（PNG、JPG、WebP）
5. 点击处理按钮
6. 验证输出的帧图像

## 2. 音频频谱可视化编辑器 (Audio Spectrum Editor)

### 获取测试音频

#### 方式一：使用浏览器录制测试音频
1. 使用 Windows 自带的录音机（Voice Recorder）
2. 或使用在线录音工具：https://voice-recorder-online.com/
3. 录制 30-60 秒的音频，保存为 MP3 或 WAV 格式

#### 方式二：生成测试音频
如果有 Python 或其他工具，可以生成测试音频：
- 使用正弦波生成不同频率的音频
- 或从音乐库获取短音频片段

#### 方式三：使用 FFmpeg 生成测试音频
```bash
# 生成 10 秒的 440Hz 正弦波音频
ffmpeg -f lavfi -i "sine=frequency=440:duration=10" -c:a libmp3lame -b:a 192k test_440hz.mp3

# 生成扫频音频（从 20Hz 到 2000Hz）
ffmpeg -f lavfi -i "aevalsrc=sin(2*PI*20*t*pow(2000/20,t/10)):d=10" -c:a libmp3lame sweep.mp3

# 生成带白噪音的音频
ffmpeg -f lavfi -i "anoisesrc=d=10:c=pink:r=44100" -c:a libmp3lame pink_noise.mp3
```

### 测试步骤
1. 上传音频文件（MP3、WAV、AAC）
2. 观察频谱可视化：
   - 播放音频时应该看到实时的频率柱状图
   - 应该看到波形线
3. 测试淡入淡出效果：
   - 设置淡入时长（如 2 秒）
   - 设置淡出时长（如 3 秒）
4. 测试音量标准化：
   - 勾选"标准化音量"
   - 设置目标音量百分比
5. 测试剪辑功能：
   - 设置开始时间和结束时间
6. 选择输出格式
7. 点击处理按钮
8. 下载并验证处理后的音频

## 3. SVG 清理优化器 (SVG Cleaner)

### 测试数据
已提供测试 SVG 文件：`sample-test.svg`

该文件包含以下可被优化的内容：
- XML 声明（可移除）
- HTML 注释
- RDF 元数据（metadata 标签）
- title 和 desc 标签
- 空的 defs 标签
- Inkscape/Sketch/Figma 命名空间和属性
- 隐藏元素（display: none）
- 空文本元素
- 深层嵌套的组（可折叠）
- 内联样式
- 冗余的默认属性
- 脚本标签
- 冗长的数值（如 200.000000000）

### 测试步骤
1. 复制 `sample-test.svg` 的内容或上传文件
2. 或粘贴任何从 Figma/Sketch/Illustrator 导出的 SVG
3. 选择优化选项：
   - **基本设置**：删除注释、元数据、编辑器数据、清理 ID、清理数值、最小化样式
   - **高级设置**：展开各选项卡查看更多选项
4. 点击处理按钮
5. 对比优化前后：
   - 查看文件大小减少百分比
   - 检查优化后的 SVG 是否能正常显示
   - 验证代码中是否移除了冗余内容

### 预期优化效果
原文件约 4KB，优化后应该能减少 40-60% 的大小，具体取决于启用的选项。

## 注意事项

1. **ffmpeg.wasm 加载**：首次使用视频/音频工具时，需要从 CDN 加载 ffmpeg-core.wasm（约 25MB），请确保网络连接正常

2. **大文件处理**：对于大视频/音频文件，处理可能需要较长时间，请耐心等待

3. **浏览器兼容性**：建议使用最新版本的 Chrome、Firefox 或 Edge 浏览器

4. **Web Audio API**：频谱可视化功能需要浏览器支持 Web Audio API（现代浏览器都支持）

5. **SVG 优化风险**：某些高级 SVG 优化可能会影响动画或交互功能，建议优化后验证 SVG 功能
